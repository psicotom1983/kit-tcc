Política de Privacidade — Kit Clínico TCC

Última atualização: 06/11/2026

1. O que é o Kit

O Kit Clínico TCC é um aplicativo de apoio para psicólogos e estagiários de Psicologia. Ele funciona no próprio aparelho do usuário e não possui servidor próprio.

2. Onde os dados ficam

Todos os dados inseridos no Kit ficam no aparelho do usuário, criptografados com a senha que ele mesmo define. O desenvolvedor do Kit não tem acesso a esses dados.

3. Uso do Google Drive

Se o usuário entrar com a conta Google, o Kit salva cópias de segurança (backups) criptografadas no Google Drive do próprio usuário. O Kit pede apenas a permissão mais restrita do Drive, que permite acessar somente os arquivos criados pelo próprio Kit. O Kit não lê, não altera e não apaga nenhum outro arquivo do Drive.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Inteligência artificial (opcional)

Se o usuário ativar a IA nas configurações, usando a sua própria chave, os textos que ele enviar para a IA são processados pela Anthropic (Claude). Esse recurso é opcional e fica desligado até o usuário ativá-lo.

5. Compartilhamento

O Kit não vende, não compartilha e não envia dados para o desenvolvedor nem para terceiros, exceto nos serviços que o próprio usuário escolher usar (Google Drive e, se ativada, a IA).

6. Responsabilidade do profissional

O usuário é responsável por cumprir o sigilo profissional, as resoluções do Conselho Federal de Psicologia e a LGPD (Lei 13.709/2018) ao registrar informações de pacientes.

7. Exclusão dos dados

O usuário pode apagar seus dados a qualquer momento, pelo próprio Kit, pelo seu Google Drive ou limpando os dados do navegador. O acesso ao Drive pode ser cancelado em myaccount.google.com/permissions.
